## Design

### 1. The stem rule (`rivals.py`)

```python
# -es after these endings is a plural marker: watches, dishes, boxes,
# dresses, quizzes. Not after a plain z (sizes -> size).
_ES = ("ches", "shes", "xes", "sses", "zzes")


def _stem(word: str) -> str:
    """Fold plurals: drop "es" after ch, sh, x, ss or zz on words longer
    than four characters (watches -> watch, glasses -> glass), keep a
    word ending in ss (glass stays glass), else drop one trailing s on
    words longer than three characters (shoes -> shoe, kids -> kid).
    ponytail: suffix rules, not a stemmer; -ies stays as is (hoodies ->
    hoodie, accessories -> accessorie); a real stemmer is the upgrade
    path if topic words start missing slugs."""
    if len(word) > 4 and word.endswith(_ES):
        return word[:-2]
    if word.endswith("ss"):
        return word
    return word[:-1] if len(word) > 3 and word.endswith("s") else word
```

- Order: the `-es` rule first (`glasses → glass`), then the `ss` keep (`glass → glass`; today `glas`), then the one-`s` rule unchanged for everything else (`shoes → shoe`, `sandals → sandal`, `mens → men`, `bus → bus`).
- Known limits (docstring, test and findings; R2): the `-es` rule also strips words whose singular ends in `-che`, `-sse` or `-xe`, so those pairs no longer meet (`caches → cach` vs `cache`; `niches → nich`, `quiches → quich`, `headaches → headach`; `mousses → mouss` vs `mousse`; `lacrosses → lacross`, `posses → poss`, `pickaxes → pickax`), whereas today the one-`s` rule folds them (`mousses → mousse`); `zzes` is right for `buzz/buzzes` and `fizz/fizzes` and wrong for `quiz` (`quizzes → quizz`, `quiz → quiz`); `-zes` after a single `z` is left to the one-`s` rule (`sizes → size`); `-oes` and `-ies` are untouched (`potatoes → potatoe`, `accessories → accessorie`, as today).
- Every caller picks the rule up. `keyword_key` for a keyword containing an affected word changes (`"men watches"`: `men watche → men watch`), so such a cached `keyword_search` row misses once (one grounded search, about 38,000 micros). (Correction, 2026-10-01, R9: it does not miss. The run's `key_map` re-keys cached rows from their stored spelling with the new `_stem` (`keyword_key(cached.keyword)`), and the cache lookup is by spelling, so such a row keeps serving. A singular and a plural spelling (`"men watch"` and `"men watches"`, or two spellings of an ss-final word) now share one key, so the change can mean fewer searches, not more.) (Note, 2026-10-01, after merge, R10: "not more" is false for the R2 limit pairs: a keyword that pairs with a cached `-che`, `-sse` or `-xe` singular (a cached "hair mousse" and a new "hair mousses") no longer shares its key, so it costs one more grounded search. And `key_map` does not rewrite any row: it maps each cached row by its stored spelling, in memory; "re-keys cached rows" above means that, not the "re-keying existing `keyword_search` rows" that Out of scope excludes.) Dev has no such keyword.

## Out of scope

- `-ies`, `-oes` and irregular plurals; a real stemmer; re-keying existing `keyword_search` rows.
- Words whose singular ends in `-che`, `-sse` or `-xe` (`caches`, `niches`, `quiches`, `headaches`, `mousses`, `lacrosses`, `posses`, `pickaxes`) and `quiz`/`quizzes`: accepted limits (R2).
